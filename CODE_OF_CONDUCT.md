# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Bit-Physics is operated by a single individual (Steven Cohen) with AI-agent
collaboration. Direct human-to-human collaboration is not currently
solicited, but any interaction with the project (issues, discussions,
emails) is expected to adhere to the Contributor Covenant.

Reports of unacceptable behavior may be sent to the maintainer through the
contact channels listed in [`SECURITY.md`](SECURITY.md).
