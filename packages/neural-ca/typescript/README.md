# neural-ca (TypeScript / Stack B)

Custom-WGSL forward **inference** for Growing Neural Cellular Automata —
**Stack B**. Phase 3 task-6 (sub-phase 3.2). Loads the converted checkpoint
(`.safetensors` → flat-f32 buffer via `neural_ca/convert_checkpoint.py`) and
rolls the NCA forward on a GPU host, producing the **B-inference** capture that
the statistical cross-stack gate-14 compares against the Stack-D (PyTorch)
D-inference capture.

**Local-only (spec § 7.8).** This path requires a WebGPU device and is NOT run
in CI; CI reads the committed B-inference capture and verifies it with a pure
NumPy oracle (`neural_ca/reference/nca_numpy.py`). Mirrors the ising
`src/metropolis.wgsl` local-only precedent.

## Layout

- `src/nca_inference.wgsl` — the forward-inference compute shader (perception
  conv + update MLP + stochastic fire mask + alpha alive-masking).
- `src/index.ts` — TypeScript driver consuming `common/common-ts` (WebGPU device
  init); the Phase-5 web-deploy path.

## Capture generation (this environment)

The local environment has no Node WebGPU runtime (only `@webgpu/types`, no
deno). The committed B-inference capture is generated by executing this same
`src/nca_inference.wgsl` via the Python `wgpu` binding (wgpu-native / Vulkan) —
see `neural_ca` `local-gpu` extra + the wgpu-py harness. The `index.ts` driver
is the deploy-path deliverable.
