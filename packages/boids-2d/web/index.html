Color · field readout
Rules
η is angular noise: at η=0 the rule is deterministic; raise it to drive the order→disorder transition (watch φ collapse). FOV below 360° gives a rear blind spot. η > 0 is still deterministic — each agent draws from hash(seed⊕step).
Interaction model
Metric = fixed radii. Topological = each boid coordinates with its k nearest neighbors regardless of distance — the empirically supported rule for starlings (Ballerini 2008, ~6–7). Separation stays metric (physical collision). Topological forces the brute broadphase and is allowed only at N ≤ 8,000; it keeps float accumulation (epsilon posture).
Species
Each species flocks within itself; a signed coupling matrix sets cross-species response (+ chase/attract, − flee/avoid) plus per-species speed. Predator–prey: a fast, rare predator chases; prey flee and clump. Segregate: mutual avoidance → immiscible flocks. Mixed: all attract → one multi-coloured flock. Cycle: i chases i+1, flees i−1 → rock-paper-scissors spirals. Count = 1 is byte-identical to the single-species rule. Multi-species uses metric neighbourhoods with float accumulation (epsilon posture); colour by Spec to see the groups.
Cursor · interact
Hover to herd (flee) or lure (bait). Place drops objects the flock flows around. Segment = click two points for a wall — chain them into channels and gauntlets. Attract flips repulsion into a sink.
Environment · flow field
Spatial fields add to wind/swirl. Double-gyre & curl-noise are incompressible (∇·u = 0 analytically); source→sink has divergence so the flock piles up. The vortex spins up a mill.
Makes η (Vicsek noise) vary in space, so order can melt in the hot region and freeze in the cold one. Needs the η slider above > 0.

Two-way GPU stable fluids on a periodic velocity grid: agents drag toward the local flow and splat the equal-and-opposite momentum back (i32 fixed point, FP = 2²⁰), then the field runs Stam advect → diffuse → project. Projection is divergence-damped (2-level V-cycle); the live residual max|∇·u| is displayed above — small, not zero. The momentum stat is field-only: agent+field totals are legitimately non-conserved because steering and the speed clamp are external forces; conservation of the exchange itself is what the Verify section's fluid rows prove. At coupling 0 every fluid pass is skipped — the run is byte-identical to the fluid-less canonical. With herd/lure held you also stir the field directly (a Gaussian impulse along the cursor's motion): stir a current, watch the flock ride it.
World · camera
World size changes the box at fixed agent count — the second phase axis ρ = N/area. Zoom is view-only; drag the canvas to pan when zoomed in. Count presets ≥ 32k auto-set the density-preserving scale √(N/4000), which can exceed this slider's range.
Initialize
Pick a starting arrangement, then Apply & reseed. Two flocks merging, or a ring relaxing into a rotating mill, are good things to watch.
Render
Counting-sort broadphase scales to 10⁵–10⁶. Presets ≥ 32k auto-set a density-preserving world scale (√(N/4000)) so neighbourhoods — hence the physics — stay invariant while the grid grows. At 10⁶ the point size floors at ~1.5 px and glow is normalized by √(4000/N) so the image neither vanishes nor blooms; HUD φ/m then come from an exact integer GPU reduction. CPU fallback is capped at 2,000.

Brute O(n²) is the exact verification oracle (allowed below 16k agents). Sort is a GPU counting sort over the uniform grid: clear → histogram → exclusive prefix-sum (work-efficient two-level Blelloch scan; the grid is capacity-clamped to ≤ 262,144 cells, so cells can grow beyond the perception radius — the 3×3 stencil stays correct, only slower) → scatter into a cell-sorted index buffer → the sim walks contiguous [start,end) ranges. No per-cell cap, nothing dropped: the neighbour set is exact. On the single-species metric path both kernels accumulate neighbour sums in i32 fixed-point (FP = 2²⁰) — integer addition is associative, so on this device brute ≡ sort bit-for-bit; the Verify section proves it in-page. Multi-species and topological keep float accumulation (epsilon posture). A live detector flags fixed-point saturation and downgrades the posture for the run. N ≥ 16k forces Sort.
Verify · distributional + device-scoped
11 headless reference-rule checks (single-step invariances, property invariants, relational trends), then a GPU · device-scoped section: scan ≡ CPU integer scan, sortedIdx is a valid cell-consistent permutation, trajectory-hash repeatability, brute ≡ sort SHA-256 equality (N=4096 · 60 steps · single-species metric), a φ-series hash at the current N (scalable bit-exact evidence even at 10⁶), and occupancy + fixed-point saturation. A fluid block (D-F8) then proves the coupled system: the cpl=0 structural gate, exchange momentum conservation, projection residual, MMS Laplacian order, advection stability, and coupled repeatability + brute ≡ sort — green means bit-exact including two-way coupling. Invariances are single-step on purpose — chaos amplifies float rounding exponentially — and cross-device correctness lives in the φ, m distributions, never in pointwise replay.
Data · export / sweeps
Exports include seed, backend, adapter identity, parameters, observables, perf, and the fixed-point saturation flag. The noise sweep runs the headless reference model across η and seeds, reporting φ, m, and χφ so the order→disorder transition can be tested rather than eyeballed.

Scrub through deterministic checkpoints, then poke differently — determinism is the gameplay feature. Stepping or pressing play from a rewind point resumes live. Rewind keeps checkpoints only up to 200k agents (memory).
Seed · shareable
Same seed + same device ⇒ single-species metric runs replay bit-for-bit on both backends (i32 fixed-point neighbour sums; proven in-page by the Verify section's trajectory SHA-256). Cross-device bit-exactness is not claimed — vendors round transcendentals (sin/cos/normalize) differently and flocking is chaotic — so cross-device correctness lives in distributions (φ, m). Multi-species and topological runs are epsilon-bounded. η > 0 stays deterministic (per-agent hash of seed⊕step). The CPU fallback is bit-exact vs itself (independent noise hash; not comparable to GPU). The link button encodes the simulation parameter state (rules, world, flow, species, engine, seed).
