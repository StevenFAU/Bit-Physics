## § 3 — Method core (from the anchor, read in full this session)

Incompressible Euler in **vorticity form on particle flow maps**: vorticity is the
evolved quantity — ω(x,t) = ℱ·ω(ψ(x),s) (Eq. 12, the Cauchy vorticity formula;
stretching enters through the forward Jacobian ℱ, no finite-difference stretching
term), with the vorticity gradient mapped as ∇ω = ℱ·∇_ψω·𝒯 + ∇ℱ·ω (Eq. 13). The
flow-map Jacobians evolve per Dℱ/Dt = ∇u·ℱ, D𝒯/Dt = −𝒯·∇u (Eq. 11 — IDENTICAL to
the U-4 (T̃, F̃) RK4 machinery), plus the paper's central innovation: **direct Hessian
evolution on particles**, D(∇ℱ)/Dt expressed in index form with (∇u, ∇∇u) source
terms (Eq. 14) — evolving ∇ℱ instead of differentiating ℱ across unstructured
particles is what buys the 3–12× longer stable flow maps. Per step: RK4 advection of
(x, ℱ, 𝒯, ∇ℱ); P2G of mapped (ω, ∇ω) via quadratic-B-spline APIC (Eq. 20, Σw
normalized); velocity reconstruction — solve ΔΨ_d = −ω_d componentwise (vector
potential, 3 scalar Poissons in 3D), u = ∇×Ψ, plus a harmonic no-through correction
ΔΦ_h = 0 for solid boundaries; dual map segments (long γ for ω — low-order quantity,
tolerates long maps; short γ for ∇ω — Eq. 21); reinit every n steps (paper n^L
20–40): redistribute, G2P (ω, ∇ω), reset ℱ=𝒯=I, ∇ℱ=0. MAC grid (ω and Ψ
edge-centred in 3D, u face-centred), quadratic B-spline transfers, AMGPCG solver in
the reference (ours: the U-4 fixed-cycle MG — deterministic by count). Solid
boundaries: cut-cell no-through + Brinkmann-penalization no-slip (Eq. 29). Reference
implementation undisclosed runtime (no public code release found at probe; Taichi
per the group's lineage) — ours is the Stack-C greenfield, CITE-DON'T-IMPORT.
