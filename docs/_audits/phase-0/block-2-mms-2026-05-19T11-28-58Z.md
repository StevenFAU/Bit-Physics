## What was built

FACT — Method of Manufactured Solutions pipeline (spec § 2.2) for the
heat equation 1D, organized under `tools/testkit/code_verification/mms/`.

FACT — Solutions library at `tools/testkit/code_verification/mms/solutions/heat_1d/`
ships the `HeatEq1DSolution` dataclass with `evaluate(x, t)`,
`source_term(x, t)`, `boundary_conditions()`, and `free_decay_rate()`.
Manufactured solution: `u(x, t) = sin(2 pi x / L) cos(t)` on `[0, L]`
with periodic BCs; not a free solution of the unaugmented PDE (the
required source has non-trivial amplitude
`D (2 pi / L)^2 cos(t) - sin(t)`).

FACT — Symbolic derivation pipeline at `tools/testkit/code_verification/mms/derive.py`
(SymPy 1.14.0). The `derive_heat_1d()` function produces the source term
as a SymPy expression; `render_markdown()` emits the deterministic
`derivation.md` report committed at
`solutions/heat_1d/derivation.md`. The runner does not re-derive at test
time per spec § 2.2.

FACT — Reference solver at `tools/testkit/code_verification/mms/solvers/heat_1d_ftcs.py`
implements forward-Euler (temporal order 1) + centered second differences
(spatial order 2) on a cell-centered periodic mesh via `np.roll`. CFL is
guarded by `c < 0.5`; the runner picks `c = 0.25` so the temporal
truncation does not dominate the spatial term.

FACT — Deliberately-broken solver at
`tools/testkit/code_verification/mms/solvers/heat_1d_broken.py` substitutes a
first-order forward difference for `u_xx`. Its observed L2 order
collapses to roughly 1.0, which the analyzer rejects against the +/- 0.5
band around formal spatial order 2.

FACT — Runner at `tools/testkit/code_verification/mms/runner.py` sweeps `N ∈ {16, 32,
64, 128}` and persists `(x, u_num, u_exact, dx, t_final)` per resolution
to `tools/testkit/code_verification/mms/tests/fixtures/heat-1d-results.h5` via h5py.
This is plain HDF5, NOT the Block-1 capture format (MMS emits analysis
state, not simulation state).

FACT — Analyzer at `tools/testkit/code_verification/mms/analyze.py` computes L2 and
L-inf errors on the cell-centered periodic mesh and fits the observed
convergence order by least-squares in log-log space. `ConvergenceResult`
exposes `passes` (True iff `|observed_order_l2 - formal_order| <=
order_tolerance`); default tolerance is +/- 0.5 per spec § 2.2 and Block 2
prompt deliverable #5.

FACT — Acceptance report at `tools/testkit/code_verification/mms/solutions/heat_1d/acceptance.md` records
observed L2 order **2.0044** and L-inf order **1.9956** on the reference
FTCS solver at the default sweep (cfl = 0.25, t_final = 0.05). Verdict
PASS (within +/- 0.5 of formal order 2).

FACT — Test suite at `tools/testkit/code_verification/mms/tests/` ships 8 tests across
four files mapping to Block-2 prompt deliverables 7a–7d:
  - `test_derive.py` (a): four tests — derive reproduces the expected

  - `test_broken_solver.py` (d): analyzer's `passes` is False on the

## Design decisions made

INFERENCE — Underscored directory names (`code_verification/`,
`heat_1d/`) instead of the hyphenated forms shown in some places of
phase-0-plan.md § 3.4. Python module paths cannot contain hyphens; the
phase-1 preflight already references `code_verification/mms` with an
underscore, so this is the consistent choice. Hyphenated directories are
used only where they are not imported (none here).

INFERENCE — Manufactured solution `u = sin(2π x / L) cos(t)` chosen over
the simpler `sin(2π x / L) exp(-t)` because the latter satisfies the
unaugmented heat equation when `D (2π / L)² = 1`, which would be too
fragile against parameter sweeps. The cosine choice guarantees a
non-vanishing source for all `D, L` and exercises both `u_t` and `u_xx`
non-trivially.

INFERENCE — Cell-centered grid `x_i = (i + 0.5) dx` with `np.roll`-based
periodic stencil. This is the most numerically-symmetric choice for
fitting observed order, since the cell-centered samples have no boundary
points that would be artificially privileged or duplicated.

INFERENCE — Default sweep parameters `cfl = 0.25, t_final = 0.05` chosen
empirically to make the spatial term dominate the temporal term at every
listed resolution (so the fitted order tracks the spatial scheme's formal
order). The eigenfunction-decay test uses `cfl = 0.25, t_final = 0.02`
and `N = 256` so the discrete-eigenvalue correction
`-4/dx² sin²(k dx / 2)` remains within 2% of the continuous eigenvalue.

INFERENCE — The broken solver's first-order forward difference is
unconditionally unstable for the pure heat equation. The runner picks
`t_final` small enough that the broken integrator remains finite long
enough for the analyzer to fit a finite order; in practice the analyzer
sees an observed L2 order near 1.0 (well under 1.5), which the negative
test asserts.

INFERENCE — The runner emits plain HDF5 (`h5py`) rather than the Block-1
capture format, matching the Block-2 prompt's explicit guidance
("...does **not** use Block 1's capture format"). MMS state is
analysis-domain, not simulation-domain; reusing the capture format would
overload its schema_version semantics.
