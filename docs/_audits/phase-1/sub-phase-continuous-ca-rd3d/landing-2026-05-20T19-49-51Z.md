### 3.3 Determinism-strategy declaration (charter § 1.5)

(FACT — module-level docstring at
`packages/reaction-diffusion-3d/reaction_diffusion_3d/sim.py`,
lines 1–66; cited verbatim in the `feat(continuous-ca-rd3d-stage1)`
commit footer.) Seven clauses underwrite the
`bit-exact-same-stack-same-hw` claim for the Python NumPy reference:

1. Stencil writes are per-cell from read-only neighbors (7-point
   Laplacian via `np.roll`; no atomic scatter, no read-after-write
   hazard).
2. No global reductions per step (pointwise update; only `np.sum`
   diagnostic — deterministic C traversal).
3. No stochastic ops inside the step (only seeded IC perturbation
   via `np.random.default_rng(seed)`; bare `np.random.*` banned).
4. Periodic BCs via `np.roll` rather than ghost-zone copy + slice
   (S1: P23 cause-#1 exemplar; see § 8).
5. No BLAS / FMA path inside the kernel (elementwise add / mul only).
6. Capture ordering is deterministic (fixed cadence, preserved h5py
   ordering).
7. Phase-2+ deferred: Stack-C atomic-scatter / driver FMA fusion /
   Vulkan subgroup-collective ops.

Gate 11's `test_run_twice_bit_exact` witnesses the resulting claim
bit-exact at i7-12700KF.
