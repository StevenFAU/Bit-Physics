## Lessons banked
- **L-CLOSE-1** — `git lfs migrate import` rewrites history (changes every
  commit SHA); on a pushed trunk the correct migration is `git add
  --renormalize`, which converts blobs to pointers in a forward commit.
- **L-CLOSE-2** — `git lfs push --object-id origin <oid>...` (args form) EOFs
  against the R2 standalone agent; the `--object-id origin --stdin` form
  succeeds. Routes to the task-9 §Q push-verification hardening.
- **L-CLOSE-3** — back-test re-audit evidence cannot live on main under
  citation scanning without an `EXCLUDED_PREFIXES` entry; landing the record is
  a two-step (exclusion, then content).
