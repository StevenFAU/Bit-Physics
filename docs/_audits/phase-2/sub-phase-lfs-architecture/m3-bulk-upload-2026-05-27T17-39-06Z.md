zstd compresses extremely well — but the operator flags that a dashboard-accounting

verdict:** the per-object `sha256` round-trip *from R2* PASSED for all 26 objects
(incl. the three 1.05 GiB MPM volumes), so the full content is cryptographically
confirmed present and intact in R2 regardless of the dashboard number. **M4**
