      probe-lean; it is now empirically refuted.

       capture-write window" WORKS and is the ONLY viable userland shim
       path.** Two writes 1.5s apart produce 0 bytes differing.

  Implication: Stage 1's CaptureWriter source-level fix (charter
  deliverable 6) MUST use path (a) global-shim form, NOT path (b)
  Module-direct form. Shape:

      const realDateNow = Date.now;
      Date.now = () => FROZEN_EPOCH_MS;
      try {
        await runHelloPhysics(...);     // or any h5wasm write
