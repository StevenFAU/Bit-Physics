## §1 — §0.3 SHIFTs taken (landed reality wins over stale plan prose)

1. **Plan §4.2.C API contract is STALE vs the landed Phase-3 surface.** The
   dispatch says "import Phase-3 symbols UNCHANGED"; the landed symbols differ
   from the §4.2.C idealization, and §0.3 makes landed reality authoritative:

   | §4.2.C plan prose | Landed Phase-3 reality (UNCHANGED, consumed as-is) |
   |---|---|
   | `GaussianSplatModel(*, n_gaussians, sh_degree=3)` + `from_pointcloud` | `GaussianSplatModel(positions, scales, rotations, opacities, sh_coefficients, *, device="cpu")`; property `num_gaussians` (NOT `n_gaussians`); no `from_pointcloud`; `load_ply`/`save_ply`/`to_numpy` present |
   | `Camera(fovx, fovy, width, height, world_view_transform, full_proj_transform, camera_center)` | `Camera(view_matrix, projection_matrix, near, far, image_height, image_width, camera_center, fov_y)` + `Camera.look_at(...)` |
   | `render(...) -> (3, H, W)` | `render(model, camera, *, background) -> (H, W, 3)` np.ndarray, CPU |

   WU-C builds `TrainingLoop`/`TrainingHistory`/`PhysicsCoupling`/viewer on the
   REAL surface and does NOT redefine the Phase-3 symbols.

2. **Submodule packages → flat src-layout modules.** Plan §4.2.C names submodule
   packages (`common_3dgs.training/`, `.splatting/`, `.viewer/`, `.coupling/`).
   Landed reality is flat modules under `src/common_3dgs/` (WU-A precedent). WU-C
   adds `training.py`, `splatting.py`, `coupling.py`, `viewer.py` modules (the
   import paths `common_3dgs.training.TrainingLoop` etc. resolve identically) and
   re-exports the public names from `__init__`.

3. **TrainingLoop optimizer posture.** The landed renderer (`render.py`) is a
   **forward** Warp rasterizer with NO differentiable tape wired. Per plan §2523
   the differentiable rasterizer is an explicit per-sim concern at Stage 4.14
   ("try gsplat-style first; SHIFTED to FD if blocked"), NOT a WU-C foundation
   deliverable. WU-C's `TrainingLoop` therefore ships the optimization-loop
   **scaffold** (fit/step interface, history tracking, densify/prune callback
   hooks) with a genuine **finite-difference reference optimizer** over a global
   appearance offset (DC SH colour + opacity logit) that demonstrably reduces
   render MSE / raises PSNR on a colour-fit target. Per-gaussian
   differentiable-rasterizer training is wired by the neural-rendered sim stages
   (4.11–4.14). This is documented in the TrainingLoop docstring + `3dgs.md`.
