# Determinism

Fixed initial state, parameters and ordered substeps reproduce bit-exact fields
on the same adapter. This is measured by fresh browser contexts in the common
web-deploy driver. Atomic operations only reduce positive wave speeds by integer
max and failure bits by OR. They do not scatter conserved quantities.

Across hardware/backends the gate compares each checkpoint against the f64
reference. Interactive pointer timing is not deterministic unless recorded.
Snapshots include the numerical clock, input ledgers and residuals.
