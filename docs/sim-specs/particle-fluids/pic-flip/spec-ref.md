## 1. Scope

A verified NumPy reference for an incompressible, free-surface, hybrid particle-grid fluid, built to the repo's TDD/13-gate standard so it can ship a Stack-B WebGPU demo with the same verification-visible moat as `eulerian-smoke`, `sph-water`, and `mpm-multimaterial`.

**Method decision (research finding 1, v0.2-corrected):** build **pure APIC** as the primary verified transfer, and expose **PIC** (stable, dissipative) and **FLIP** (low-dissipation, noisy) as comparison modes — **not** a tuned PIC/FLIP α-blend as the canonical mode. The APIC authors show pure APIC is superior to APIC/PIC blends (unlike FLIP, where the blend is standard). **Citation correction (v0.2, verified):** arXiv:2603.03860 (Yao & Zhao 2026) does **not** reaffirm this — it *proposes* an adaptive APIC/PIC blend (a soft-switch attenuating the affine term where local particle support is thin), in a compressible/shock-capturing context. It is retained only as a counterpoint citation, not a reliance; the pure-APIC decision rests on Jiang 2015 and stands for this incompressible scope. The three-way PIC/FLIP/APIC comparison is a verification asset, not just a toggle (§ 6, § 10). A *labeled, live-only* FLIP-ratio slider (0.9–0.99, the industry-standard blend; Ten Minute Physics ships 0.9) is allowed in the web demo as pedagogy — never in a canonical or gated path.

**Grid decision (research finding 9 + caveats — a real fork, stated honestly):** build the **collocated grid first**, MAC-staggered as a documented v2 upgrade. Rationale:
- The repo's verified pressure projection (`eulerian-smoke` `project_pressure`) is **collocated** — collocated-first reuses it directly (§ 6.1, § 7).
- APIC's angular-momentum conservation was **originally proven on a collocated grid** (Jiang 2015 tech report Props 5.4/5.5 — implicitly collocated: one full velocity vector per node; the tech doc never names the grid type). Exact transfer-level conservation on a **staggered MAC** grid was only resolved by **Ding, Shinar & Schroeder 2020** (JCP 408, 109311 — *not* "Jiang et al. 2017/2020" as v0.1 said; the 2017 JCP paper is collocated-only, verified: its text contains no MAC/staggered discussion). Collocated-first lets us claim the *proven* property without adopting the later formulation.
- The literature's specific per-axis MAC-APIC transfer recipe was **refuted 0-3** in the research, so the MAC path is less certain from sources; the collocated transfer is unambiguous.
- Consistency with `eulerian-smoke`: same collocated-first + staggered-v2 arc, same honest checkerboard-null-space story (§ 6, and the smoke spec § 2/§ 4.3).

The cost — collocated central-difference projection admits the checkerboard null-space (Gagniere 2020's wording: "staggering prevents pressure null modes") — is a *documented, verification-visible* property (shared with `eulerian-smoke`), not a hidden defect. MAC-staggered v2 (canonical Zhu/Bridson FLIP grid + the Ding 2020 APIC-MAC conservation proof + no checkerboard) is the natural follow-up.

**Projection-reuse correction (v0.2 — load-bearing, repo-audited):** the verified smoke projection (`packages/eulerian-smoke/eulerian_smoke/reference/stable_fluids.py:255`; 3D at `packages/eulerian-smoke/eulerian_smoke/reference/stable_fluids.py:442`) is **periodic-BC only** — every neighbor read is a rolled/wrapped index; it has no solid-wall Neumann BC, no free-surface Dirichlet BC, no per-cell fluid mask, and no variable-domain machinery. A free-surface dam-break needs all four. What actually transfers from smoke: the collocated central-difference divergence/gradient/Laplacian **operator shapes**, the fixed-iteration Jacobi **structure** (the P24 no-early-stop pattern), and the MMS **protocol**. The **masked free-surface Poisson is NEW verified code** (`poisson_masked` module, § 5): per-step cell labels {solid, fluid, air} derived from marker occupancy, Dirichlet `p = 0` in air cells, zero-weight solid faces (per-face scalar `s ∈ {0,1}`, the Zhu/Bridson/Müller pattern — this is also what makes *moving* obstacles exert velocity BCs), Jacobi sweeps restricted to fluid cells. It gets its own verification (§ 6.1) — the inherited periodic MMS does **not** cover it. v0.1's "reusing the smoke projection directly" overstated the reuse.

**Operator-pair correction (v0.3 — measured at execution, forced by the § 6.3 hydrostatic anchor):** the masked solver does **not** reuse the smoke central/central divergence/gradient pair. On a periodic domain that pair costs only the documented O(dx²) wide-operator interior floor; at a free surface it fails at **O(1)** — a settled column solved with central operators retains half of gravity per step and sinks (closed-form derivation in `algebraic.md` § 4). The masked projection therefore uses the **adjoint compact pair** (backward-difference divergence + forward-difference gradient), which composes to exactly the compact 5/7-point Laplacian the Jacobi sweep iterates, reproduces the discrete hydrostatic profile `p = ρg·depth` **exactly** (measured `dP/dy = −9.810` at convergence), and has no checkerboard null mode. Equivalent to reading the collocated component `u[i]` as the MAC face `(i, i+1)` — the velocities stay collocated for the transfers (the APIC proofs are untouched); only the projection differencing changes. The smoke "operator shapes transfer" claim is hereby narrowed to: Jacobi structure + fixed-cap pattern + MMS protocol.

**Dimensionality decision (v0.2 — previously unstated):** the reference implements **2D and 3D**, the smoke pattern (2D primitives + `_3d` siblings). MMS/order ladders and most PBT run in 2D (cheap, per `eulerian-smoke`); the **canonical dam-break capture is 3D**, because the web demo reuses `sph-water`'s screen-space renderer, which presumes 3D particle positions (billboard depth impostors), and every fluid sibling's web canonical is 3D (sph-water 100K particles; mpm-multimaterial 16³ gate / 128³ offline). The rotating-disk angular-momentum showcase runs in 2D (where `L` is a scalar and the plot is unambiguous) with a 3D preset variant.

Out of scope for the reference: viscosity/surface-tension forces (inviscid free-surface only), two-phase coupling, adaptive/sparse grids, the collocated variational Taylor-Hood projection (Gagniere et al. 2020 — a documented future alternative, § 12).

## 3. Algorithm

One APIC step (collocated grid, quadratic B-spline weights `wᵢₚ`, `Dp⁻¹ = 4/dx²`):
1. **P2G (affine, lumped mass):** `mᵢ = Σₚ wᵢₚ mₚ`; `mᵢvᵢ = Σₚ wᵢₚ mₚ (vₚ + Bₚ Dp⁻¹ (xᵢ − xₚ))`; `vᵢ = mᵢvᵢ / mᵢ`. Lumped (diagonal) mass ⇒ per-node independent accumulate+divide.
2. **Grid update:** apply gravity; label cells {solid, fluid, air} from marker occupancy; **masked pressure projection** (NEW verified code, § 1 correction) — solve `∇²p = (ρ/Δt)∇·u*` on fluid cells only, Dirichlet `p=0` in air, zero-weight solid faces, fixed-iteration Jacobi (structure ported from smoke, not the function); subtract `(Δt/ρ)∇p` ⇒ discretely divergence-free `vᵢⁿ⁺¹` (up to the collocated O(dx²) floor).
3. **Post-projection BC pass (order matters — v0.2):** restore solid-adjacent velocities to the obstacle's velocity (`u·n = v_solid`; this, not just static masking, is what makes *moving* obstacles push fluid — the Ten Minute Physics draggable-ball pattern), then **extrapolate grid velocities into air cells** (breadth-first, ≥2 layers; Bridson's standard recipe — without it, surface particles drag against phantom zero velocities and splashes die sticky and damped).
4. **G2P (affine reconstruction):** `vₚⁿ⁺¹ = Σᵢ wᵢₚ vᵢⁿ⁺¹`; `Bₚ = Σᵢ wᵢₚ vᵢⁿ⁺¹ (xᵢ − xₚ)ᵀ`; `Cₚ = Bₚ Dp⁻¹`. (**PIC** mode: keep `vₚ = Σ wᵢₚ vᵢ`, `Bₚ ≡ 0`. **FLIP** mode: `vₚ += Σ wᵢₚ (vᵢⁿ⁺¹ − vᵢ*)`.)
5. **Advect:** move particles through the grid velocity field with **RK2** (Zhu/Bridson), CFL-limited substeps.
6. **Position regularizers (v0.2 — documented, toggleable, declared):**
   - **Push-apart:** 2 iterations of symmetric positional projection on pairs closer than `2·rₚ` via a particle cell hash (`s = 0.5·(minDist−d)/d`, move each ±s·Δx; Müller's exact recipe). Fixes post-impact clumping/boiling.
   - **Density drift compensation:** scatter a scalar particle density ρ to cell centers; add a **one-sided** RHS source where ρ>ρ₀, realising the corrective expansion `div(u') = k·max(ρ/ρ₀−1, 0)/dt`. **v0.3 normalization corrections (measured, still-pool-forced):** (a) ρ₀ = the frame-0 **max** over fluid cells, not the mean — surface cells always read low, so a mean threshold fires *at rest*, violating § 6.6 invariant 6; (b) default **k = 0.05** (excess relaxed over ~20 steps) — full-per-step k=1 is unstable against a *converged* masked solve (corrective velocity ~ excess·dx/dt; the still pool explodes to ~8 m/s, linearly in k; Müller's demo tolerates his k=1 because his 20–40-iteration unconverged solve low-passes the source). Fixes the secular volume loss every velocity-only-projection PIC/FLIP exhibits.

   Both are **non-physical regularizers, stated as such** (Müller's slides call the pair "necessary", and his demo ships the same toggle to prove it): **OFF** for every closed-form golden and transfer-level invariant (§ 6.6/§ 7 are dt=0 statements — unaffected either way), **ON (declared in provenance)** for the canonical captures and the live demo. The web demo ships the toggle as a *teachable failure mode* — turn it off and watch the volume readout drift (web spec § 4.3).

Free surface: **marker particles** (Zhu/Bridson eliminate the particle-level-set); a cell is fluid iff it holds ≥1 particle.

**Integrator note (research caveat 1 — load-bearing; source corrected v0.2):** APIC's angular-momentum conservation is exact *at the transfer level and at dt=0 for the round trip*. End-to-end (full-step) conservation additionally requires an **angular-momentum-conserving integrator (symplectic Euler λ=0 or midpoint λ=½)** — forward/backward Euler and trapezoid do **not** conserve. **Cite Jiang 2017 JCP for this** (verified quote: "schemes such as forward Euler, backward Euler, and trapezoid rule do not conserve angular momentum"; also: the 2015 transfers "are discretely angular momentum conserving only for explicit symplectic Euler integration") — the 2015 tech doc contains **no** integrator discussion (verified), so it must not be cited for this caveat. The reference uses symplectic Euler; the golden angular-momentum test (§ 7) is stated at the transfer level (exact), and the full-sim diagnostic (§ 10) is reported with this caveat. Note also the regularizers (step 6) sit *outside* the conservative core — the full-sim `L(t)` diagnostic is reported for the rotating-disk scene with regularizers OFF (they are inert there anyway: a rigid rotation neither clumps nor compresses).

## 4. Algebraic form

Full derivation in `algebraic.md` (authored at execution, 2026-07-04, alongside the golden generators — the `sph-water` sibling-dir convention). Summary: APIC augments each particle with an affine matrix `Cₚ = Bₚ Dp⁻¹`; `Dp = Σᵢ wᵢₚ (xᵢ−xₚ)(xᵢ−xₚ)ᵀ = (1/4)dx²I` for the quadratic stencil (closed form, research finding 4). The pressure Poisson uses the **adjoint compact operator pair** (backward div + forward grad; § 1 v0.3 correction — the smoke central pair fails the hydrostatic anchor at O(1) on a free surface; derivation `algebraic.md` § 4). The composed operator is exactly the compact 5/7-point Laplacian — no wide-operator residual floor and no checkerboard null mode for this pair.

## 6. Verification posture

Roy 2005 levels; the moat is unusually strong because APIC's signature properties are **formally proven exact equalities**, not tolerances.

### 6.1 Code verification (MMS / order-of-accuracy)
- **Pressure-Poisson order-of-accuracy (periodic interior)** — reuse the `eulerian-smoke` manufactured-solution protocol (`test_mms_convergence.py`): the collocated projection is p≈2 on the N∈{32,64,128} ladder. Directly transferable for the *interior operator only* (identical stencils).
- **Masked free-surface Poisson verification (v0.2 — NEW; the periodic MMS does not cover it):** a manufactured solution on a fixed irregular fluid mask — exact `p` imposed as Dirichlet data on air cells, zero-flux solid faces — N-ladder with p≈2 expected in the interior and the measured order *at the boundary* declared (first-order at the voxelized free surface is the honest expectation for this discretization; stated, not hidden). Plus the § 6.3 hydrostatic analytic as the BC-correctness anchor.
- **Advection order-of-accuracy (Burgers protocol, Gagniere 2020 / arXiv:2003.12227):** advect an exact quadratic solution under `Du/Dt=0` through the full transfer cycle, refine `dt=dx`, fit `log‖e‖∞` vs `log dx` — slope ≈1 (the expected order for the resampling chain; **not** a defect — stated as the measured order). **v0.3 measured (2026-07-04):** quadratic shear profile, N ∈ {16,32,64,128} ladder — pairwise slopes 0.58 (pre-asymptotic) / 0.93 / **1.07**; pinned assertion: finest-pair slope ≥ 0.9 (`packages/pic-flip/tests/test_advection_ooa.py`).

### 6.2 Solution verification
- Grid-refinement convergence (Richardson) on the dam-break / rotating-disk canonical; GCI reported.

### 6.3 Model validation (analytic)
- **Hydrostatic pressure column:** a settled column reproduces `p = ρg h` linearly with depth (to a measured tolerance) — the standard incompressible-fluid analytic check.
- **Solver-depth honesty (v0.2 — GPU Gems 3 ch. 30):** Jacobi propagates boundary information ~one cell per sweep, so a fixed-`n_iter` solve cannot even *represent* `p = ρgh` in a column deeper than `n_iter` cells (the documented "water slowly sinks through the bottom of the tank" failure), and full convergence scales ~O(depth²) sweeps. The smoke default of 20 iterations is **far too few** for any interesting water depth. Therefore: every canonical declares its `(grid depth, n_iter)` pair with `n_iter` chosen by **measured convergence** on the hydrostatic column (residual plateau), not inherited; fixed-cap determinism (§ 8) is preserved because the cap is per-canonical and pinned. **v0.3 measured (24-grid, 15-deep column, 2026-07-04):** 20 sweeps retain **100 %** of `g·dt` (the sinking failure, now pinned as a *documented-failure test*), 1000 → 8.4 %, 2000 → 0.55 %, 4000 → < 0.01 % with `dP/dy = −9.810` exactly; canonical cap pinned at **3000** (< 0.1 % band), diagnostic-tier (12³) at 600. The drift-compensation regularizer masks the *volume* symptom but not the pressure error — it must not be used to paper over an unconverged solve (test: hydrostatic runs with regularizers OFF).
- **Still-pool-stays-still:** a pool at rest develops no spurious currents (max |v| stays below a measured floor) — a null-test for transfer/projection bias. Run **twice**: regularizers OFF, and ON (they must be inert at rest — § 6.6 invariant 6).

### 6.4 Calculation validation
- **Rotating-disk / rigid-rotation angular momentum** (Jiang 2017 JCP § 6.1, Fig. 3): APIC conserves total angular momentum across the run (to the integrator's order); PIC visibly damps it; FLIP is noisy. The signature demonstration (§ 7 golden is the exact transfer-level statement; this is the full-sim validation).
- **Dam-break** canonical capture (the shippable scene).

### 6.6 PBT-covered invariants (≥ 2 per R9)
1. **Partition-of-unity** `Σᵢ wᵢₚ = 1` (reuse the MPM invariant surface).
2. **Mass & momentum conservation across P2G/G2P** `Σₚ mₚ = Σᵢ mᵢ`, `Σₚ mₚvₚ = Σᵢ mᵢvᵢ` (reuse the MPM invariant).
3. **Divergence-free post-projection** `‖∇·u‖∞ ≤ tol` (reuse the smoke invariant + its collocated O(dx²) floor).
4. **APIC affine round-trip preservation** (Prop 5.1): at dt=0, an affine field `v+Cx` (incl. pure rotation `ω×x`) is reproduced through G2P→P2G to machine precision; PIC is **not** (a paired negative control).
5. **Angular-momentum conservation across a transfer** (Props 5.4/5.5): total angular momentum is invariant across P2G and across G2P for APIC (exact in exact arithmetic; § 7 FP-honesty note governs the asserted tolerance); PIC's G2P is **not** (paired negative control).
6. **Regularizer inertness at rest (v0.2):** on a settled configuration, push-apart displaces nothing (all pair distances ≥ 2rₚ) and the drift term is identically zero (ρ ≤ ρ₀ everywhere) — the § 3 step-6 regularizers cannot inject energy into the § 6.3 still-pool null test.

## 8. Determinism

`bit-exact-same-hw` (matching `eulerian-smoke`/`mpm-multimaterial`). Load-bearing clauses:
- Lex-order particle + stencil iteration; **no atomic scatter** in the CPU reference; fixed accumulation order ⇒ bit-identical FP residual across runs (MPM pattern).
- Fixed-iteration-cap Jacobi projection (no tolerance early-stop branch) — the smoke/MPM P24 pattern; the cap is per-canonical, chosen by measured hydrostatic convergence (§ 6.3), then pinned.
- RNG threaded through `common_py.determinism.Config`; bare `numpy.random.*` banned in the reference.
- APIC's **lumped diagonal mass** ⇒ per-node independent accumulate (no coupled solve) — this is also what makes the *web* fixed-point-atomic P2G determinism cheap (§ 9; research finding 6). FLIP's exact conservation would need a full (possibly singular) mass matrix — a coupled solve that is far harder to bit-reproduce; another reason APIC is primary.

## 9. Equivalence

- Cross-mode: PIC/FLIP/APIC share the P2G/grid/G2P scaffold; only the reconstruction differs — tested for structural equivalence where they must agree (e.g. P2G is identical; PIC ≡ APIC with `Bₚ≡0`).
- **Web WGSL port equivalence (the frontend gate):** the WebGPU f32 + fixed-point-integer-atomic P2G reproduces the reference to a measured tolerance; run-twice byte-identical on-device. Because the canonical trajectory is chaos-sensitive, the web gate is `new_canonical` (closed-form goldens + transfer bit-identity + robust observables), per the web spec — NOT per-particle capture. Fixed-point P2G is bit-identical to a *fixed-point* oracle, not the f32 lex-order reference (the MPM subtlety); stated honestly.

## 10. Diagnostics

Per-step: total **kinetic energy** (PIC decays / FLIP noisy / APIC stable — the comparison), total **linear & angular momentum** (with the integrator caveat), max **divergence** (‖∇·u‖∞, the collocated floor), max velocity (CFL), particle/cell counts, and (v0.2) **total fluid volume / water level** (fluid-cell count + per-column max marker height) — the drift-compensation readout: flat with the regularizer ON, secularly sinking with it OFF (the teachable failure, web spec § 4.3). These double as the web PROVE-layer overlays.
