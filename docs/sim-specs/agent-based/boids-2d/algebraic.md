# Algebraic Notes

Core observables:

- Polarization: normalized magnitude of the summed unit velocity vectors.
- Rotation: normalized angular momentum about the current center of mass.
- Susceptibility: finite-window variance of polarization scaled by agent count.
- Fluid projection residual: measured divergence/pressure-solve residual, not
  asserted to be zero.

The app labels Tunström-style regimes using polarization and rotation thresholds:
polarized, milling, swarm, and transitional.
