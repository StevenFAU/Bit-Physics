# Determinism

The primary exactness claim is path-scoped on one device: the single-species
metric WebGPU path uses order-independent fixed-point neighbor accumulation, so
the in-page proof can compare brute and sorted-grid trajectories by hash.

Cross-device bit identity is not claimed. Browser deployment uses run-twice
identity for the emitted deterministic observable capture and relies on the
page's own GPU proof panel for adapter-local brute-sort and coupled-fluid rows.
