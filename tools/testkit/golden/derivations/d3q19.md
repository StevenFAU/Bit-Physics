## 1. Lattice geometry

The D3Q19 discrete velocity set has 19 directions:

| Group | Velocities | Count | Speed magnitude |
|---|---|---|---|
| Rest | $(0, 0, 0)$ | 1 | 0 |
| Face neighbors | $(\pm 1, 0, 0), (0, \pm 1, 0), (0, 0, \pm 1)$ | 6 | 1 |
| Edge neighbors | $(\pm 1, \pm 1, 0), (\pm 1, 0, \pm 1), (0, \pm 1, \pm 1)$ | 12 | $\sqrt 2$ |

The numbering convention used by the table at
`tools/testkit/golden/tables/lattice/d3q19-equilibrium.json` is

| Index | Vector |
|---|---|
| 0 | $(0, 0, 0)$ |
| 1, 2 | $(\pm 1, 0, 0)$ |
| 3, 4 | $(0, \pm 1, 0)$ |
| 5, 6 | $(0, 0, \pm 1)$ |
| 7..10 | $(\pm 1, \pm 1, 0)$ (xy-plane edges) |
| 11..14 | $(\pm 1, 0, \pm 1)$ (xz-plane edges) |
| 15..18 | $(0, \pm 1, \pm 1)$ (yz-plane edges) |

## 2. Weights

Standard Gauss-Hermite quadrature weights for the D3Q19 lattice
(Qian et al. 1992 § 2; Krüger 2017 Ch. 3):

| Group | Weight |
|---|---|
| Rest | $w_{0} = 1/3$ |
| Face | $w_{1..6} = 1/18$ |
| Edge | $w_{7..18} = 1/36$ |

These satisfy $\sum_{i=0}^{18} w_{i} = 1$ (verified: $1/3 + 6 \cdot 1/18 + 12 \cdot 1/36 = 1/3 + 1/3 + 1/3 = 1$).

## 3. Sound speed

The D3Q19 lattice has $c_{s}^{2} = 1/3$ in lattice units, so $c_{s} =
1/\sqrt 3 \approx 0.5774$. The relativistic-form derivation comes
from matching the second velocity moment to the ideal-gas
equation-of-state under Gauss-Hermite quadrature.

## 4. Equilibrium distribution (BGK)

Per Qian, d'Humières & Lallemand 1992 eq. (3a):

$$f_{i}^{\mathrm{eq}}(\rho, \mathbf{u}) = w_{i}\,\rho\,\Bigl[1 + \frac{\mathbf{c}_{i}\cdot\mathbf{u}}{c_{s}^{2}} + \frac{(\mathbf{c}_{i}\cdot\mathbf{u})^{2}}{2\,c_{s}^{4}} - \frac{\mathbf{u}\cdot\mathbf{u}}{2\,c_{s}^{2}}\Bigr].$$

This is the second-order truncation of the Maxwell-Boltzmann
distribution in $|\mathbf{u}|/c_{s}$.

## 5. Moment-matching invariants

The equilibrium satisfies (Krüger 2017 Ch. 3):

- $\sum_{i} f_{i}^{\mathrm{eq}} = \rho$.
- $\sum_{i} \mathbf{c}_{i}\,f_{i}^{\mathrm{eq}} = \rho\,\mathbf{u}$.
- $\sum_{i} \mathbf{c}_{i}\otimes\mathbf{c}_{i}\,f_{i}^{\mathrm{eq}} = \rho\,\mathbf{u}\otimes\mathbf{u} + \rho\,c_{s}^{2}\,\mathbf{I}$.

The golden table commits the 19 $f_{i}^{\mathrm{eq}}$ values at one
fixed test point $(\rho, \mathbf{u}) = (1, (0.1, 0, 0))$ and the
density-+-momentum moments as a sum invariant.
