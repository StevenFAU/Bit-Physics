# Derivation — 3dgs-mpm-sh-update SH-rotation golden (`3dgs-mpm-sh-rotation.json`)

> Gate-4 numerical golden for the degree-1 spherical-harmonic rotation under deformation
> (PhysGaussian Eq. (9), arXiv:2311.12198 — CITE-ONLY; reimplemented per spec § 2.4). Three
> independent, source-named anchors. The expected values are produced by an INDEPENDENT
> dipole-rotation oracle (a different computation path from the `P R Pᵀ` implementation under
> test) and cross-checked equal to the implementation to 1e-12.

## Setup

PhysGaussian rotates each Gaussian's view-dependent appearance by the rotation part `R` of the
polar decomposition `F = R S` of the per-particle deformation gradient. The common-3dgs
renderer evaluates the degree-1 band as `−C1·y·c₁ + C1·z·c₂ − C1·x·c₃`
(`common/common-3dgs/src/common_3dgs/render.py:87`), so the band-1 basis values are
`(−y, +z, −x)·C1`. Writing the signed permutation `P = [[0,−1,0],[0,0,1],[−1,0,0]]` (the
band-1 basis vector is `v(d) = P·d`), rotation-equivariance `eval_SH(D₁(R)·c, R·d) =
eval_SH(c, d)` forces the closed form

    D₁(R) = P · R · Pᵀ.

**Independent dipole derivation (same result, distinct path).** The degree-1 band is a linear
functional `f(d) = C1·(−c₁·y + c₂·z − c₃·x)`, whose gradient (dipole vector) is
`a = C1·(−c₃, −c₁, c₂)`. Rotating the function by `R` rotates the dipole: `a' = R·a`. Mapping
`a'` back to coefficients (`a = C1·(−c₃, −c₁, c₂)` ⇒ `c₁ = −a_y/C1`, `c₂ = a_z/C1`,
`c₃ = −a_x/C1`) yields `c'`. This reduces algebraically to `c' = P R Pᵀ c` (the `C1` cancels),
so it is a *same-theory* cross-check of the closed form — but a genuinely different derivation
and code path. The golden's expected values are generated by this dipole oracle.

## Anchors

1. **`anchor1-closed-form`** — `D₁(R) = P R Pᵀ` (matrix algebra), `R = R_z(90°)`. Hand-verified
   headline value: band-1 coefficient `c = (1, 0, 0)` rotates to `(0, 0, −1)`
   (`R_z(90°)` sends the dipole `(0,−1,0)` → `(1,0,0)`, which maps back to `c' = (0,0,−1)`).
   Source: closed-form Wigner-D against the renderer basis.

2. **`anchor2-dipole-rotation`** — the independent dipole-vector rotation, `R = R_x(90°)`, a
   richer multi-channel band-1. Same-theory caveat (reduces to `D₁`), distinct derivation.

3. **`anchor3-identity-frozen`** — `R = I` leaves the SH unchanged (recovers the task-8 MVP
   "SH frozen" as the `R = I` special case). Fully independent degenerate anchor.

Tolerance `1e-12` absolute (`tools/testkit/equivalence/tolerance.toml`
`[golden_tolerance.neural-rendered.3dgs-mpm-sh-update]` `sh_rotation_abs`). The implementation
(`packages/3dgs-mpm-sh-update/gs_mpm_sh_update/sh_rotation.py`) matches all three to 1e-12.
