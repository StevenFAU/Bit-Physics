GPU-accelerated physics & emergence — a portfolio with a verification spine

Interactive simulations — smoke, flocks, chemical gardens, slime intelligence, critical magnets, learned life, fractal geometry, chaos — each running real compute kernels in your browser over WebGPU. Built solo with AI agents under an audit discipline where every claim is measured before it is declared, and the full evidence trail ships with the code.

Every simulation below passed its own verification gate — the strongest check its physics admits, from byte-exact reproducibility to agreement with a high-precision reference or exact textbook laws — inside a real browser-WebGPU session, before it was published here. Each card names its gate; how it all works lives on the methodology page.

How this is verified

The differentiator isn’t the pixels — it’s that every pixel is downstream of a gate. Three gate kinds cover every simulation above:

capture_roundtrip

The browser build replays the sim and its captured state is compared field-by-field against the committed canonical capture — to a declared tolerance for Gray-Scott (rel 1e-4), and bit-exact for Neural CA. Same physics, proven, not asserted.

observable

Where single trajectories legitimately diverge (Monte Carlo), the gate checks physics observables: the Ising browser run’s energy-per-spin must sit within the CPU reference ensemble (z < 3). Statistical honesty instead of false exactness.

new_canonical + run-twice

Chaotic and agent-based sims pin a browser-canonical capture: two independent runs must be byte-identical (determinism), plus per-sim invariants — speed clamps, on-attractor envelopes, mass conservation — hold over the whole capture.

Audits close with four-state verdicts — CONFIRMED / SHIFTED / REFUTED / DEFERRED — and the rule that makes them mean something: tolerances are measured, then declared — never widened to make a failing gate pass. When reality disagrees with the plan, the audit records the SHIFT; the ledger is append-only, so no claim is ever silently rewritten.
